# ①課題名
羽田発ミステリーツアー

## ②課題内容（どんな作品か）
- 予算を選ぶと、行き先がランダムで決まり、写真つきの切符が出てくる旅のアプリです。

- https://makikonakaba-bit.github.io/mystery-tour/

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 今回なし
- PW: 今回なし

## ⑤工夫した点・こだわった点
- じゃんけんの「自分の手」と「コンピューターの手」を、「予算」と「行き先」に置きかえました。
- どのボタンでもコンピューターが出すのは1〜3の同じ3パターンですが、その組み合わせ9通りに、9か所の行き先と写真を割り当てています。
- 切符は fadeIn で1秒かけてふわっと出して、どこに行くのか少しドキドキする間を作りました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 課題どおりにじゃんけんアプリを作ってみましたが、私はリアルなじゃんけんでも「勝ち負け」が混乱することが多く、勝ち・負け・あいこで何を表示するのか頭がこんがらがりました。正しい組み合わせは、Claude Codeに教えてもらいました。
- 前回の復習もしたかったので、もう一つ違うアプリを作ることに決めました。色を変えたり、写真を入れたり、枠を作ったりする方法を、すでに忘れていたことにショックを受けました。打ち間違いも多く、最終的な実装はかなりAIに頼りました。
- 次回は、出発見送りにトライしたいです。
